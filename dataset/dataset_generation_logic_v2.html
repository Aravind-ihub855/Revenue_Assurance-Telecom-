7 Mediation Record — simulate mediation layer effects depends on: CDR NEW — Fix 5
One mediation_record per CDR row — even rejected ones get a row (with processing_status = rejected).
Processing status logic
if cdr.record_status == "duplicate": mediation.processing_status = "duplicate" mediation.duplicate_flag = True elif cdr.record_status == "invalid": mediation.processing_status = "rejected" mediation.rejection_reason = random choice from rejection codes elif random() < 0.01: # 1% of valid CDRs fail mediation mediation.processing_status = "rejected" mediation.rejection_reason = "transformation_error" else: mediation.processing_status = "success" mediation.normalized_usage_value = apply_normalization(cdr) mediation.rated_units = apply_pulse(cdr, plan)
Normalization logic
For voice: normalized_usage_value = duration_seconds (raw seconds) rated_units = ceil(duration_seconds / pulse_seconds) * pulse_seconds # e.g. 125 sec, pulse=60 → ceil(125/60)=3 → rated_units = 180 sec For data: normalized_usage_value = (uplink + downlink) / (1024*1024) # → MB rated_units = normalized_usage_value # per MB For SMS: normalized_usage_value = sms_count rated_units = segment_count from sms_detail (fetched later)
Rejection reason codes
RC001 = missing_mandatory_field RC002 = invalid_duration (duration <= 0) RC003 = future_timestamp RC004 = unknown_subscriber RC005 = transformation_error RC006 = duplicate_sequence_number

9 Billing Record — complete correct logic + noise injection depends on: mediation_record (success rows only), tariff_rate, plan_history Fix 2 + Fix 4 + Fix 5
Step A — Use ONLY successfully mediated CDRs
billable_cdrs = mediation_records .filter(customer_id, billing_cycle_id) .filter(processing_status == "success") # Rejected + duplicate mediation rows are excluded from billing # This is how mediation layer creates revenue leakage
Step B — Voice charge with pulse rounding (Fix 2)
for each voice mediation row: rated_units = mediation.rated_units # already pulse-rounded call_type = cdr.call_type # local / STD / ISD rate = lookup(plan_id, "voice", call_type) if plan.voice_unlimited_flag: charge = 0.0 else: free_used = min(free_remaining, rated_units / 60) free_remaining -= free_used chargeable_min = max(0, rated_units/60 - free_used) charge = chargeable_min * rate.rate_per_unit
Step C — Data charge with per-day FUP (Fix 3)
for each data mediation row: session_mb = mediation.normalized_usage_value throttled = data_session.throttled_flag if throttled: # post-FUP bytes charged at overage rate normal_mb = max(0, plan.daily_data_mb - daily_used_before) overage_mb = session_mb - normal_mb charge = (normal_mb * rate.rate_per_unit) + (overage_mb * rate.overage_rate) else: charge = 0.0 # within free allowance
Step D — SMS charge with segment logic (Fix 2)
for each sms mediation row: billable_units = sms_detail.segment_count # 1, 2, or 3 free_remaining_sms -= billable_units chargeable = max(0, billable_units - free_remaining_sms) charge = chargeable * rate.rate_per_unit
Step E — Inter-operator charge (Fix 2)
if cdr.inter_operator_flag == True: # override rate with STD/off-net rate rate = lookup(plan_id, "voice", "STD") # even if call_type was "local" — inter-op always gets STD rate
Step F — Anomaly injection with noise (Fix 4)
ANOMALY TYPES and HOW: underbilling (4%): apply free_voice mins to STD/ISD calls (wrong) → voice_charge is too low overbilling (2%): apply peak rate to ALL calls ignoring time → voice_charge is too high tariff_mismatch(2%):use wrong plan's rates (old plan before upgrade) → charge based on previous_plan_id rates missing_cdr (1%): skip 3–5 CDR rows for customer in one cycle → billing total < CDR total zero_charge (1%): set one service charge to 0 (bug simulation) → data_charge or sms_charge = 0.0 # Store the correct_expected_amount separately as ground truth correct_total_charge = correctly computed amount actual_billed_charge = amount after anomaly injection variance = correct_total_charge - actual_billed_charge
Step G — Final amount assembly
base_charge = plan.plan_price voice_charge = (from Step B or anomaly version) data_charge = (from Step C or anomaly version) sms_charge = (from Step D) roaming_charge = (if any roaming CDRs) subtotal = base_charge + voice_charge + data_charge + sms_charge + roaming_charge discount = random 0–5% of subtotal tax_amount = subtotal * 18% total_charge = subtotal - discount + tax_amount # Ground truth label stored in anomaly_ground_truth.csv anomaly_type = underbilling | overbilling | tariff_mismatch | missing_cdr | zero_charge | None correct_total_charge = amount without anomaly variance_amount = correct_total_charge - total_charge
